# Alert

Encadré de message dans le flux de la page : avertissement, information ou erreur qui concerne toute la page (« 3 demandes à relancer », « Hors ligne »).

- Fond `warning-soft`, `info-soft` ou `danger-soft`, icône de la couleur pleine, texte `ink`.
- Une phrase qui dit la situation, puis l'action proposée en lien ou bouton `ghost`.
- Pour un retour après action, utiliser `Toast` ; pour une erreur de champ, l'erreur du `Field`.
