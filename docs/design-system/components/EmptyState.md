# EmptyState

Ce qu'affiche une liste ou une page sans contenu : une icône, une phrase qui dit pourquoi c'est vide, l'action qui le remplit. Remplace les « Aucune donnée. » actuels.

- Icône 24px dans un disque `brand-soft` de 56px, titre `title-md`, explication `ink-muted` (une ou deux phrases), un bouton primary ou secondary.
- Distinguer « rien encore » (inviter à créer) de « rien pour ce filtre » (proposer d'effacer les filtres).
