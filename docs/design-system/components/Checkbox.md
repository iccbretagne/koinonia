# Checkbox

Case à cocher 20px dans une ligne cliquable de 44px ; remplace `CheckboxGroup` et les cases natives de `DataTable`.

- Case bordée `control-line`, cochée en aplat `brand` avec coche `on-brand`.
- Tout le libellé est cliquable. En groupe : un `fieldset` avec une `legend` au style `label`.
- Pour un réglage qui s'applique immédiatement (préférence de notification), préférer un interrupteur ; la case est pour ce qui sera enregistré avec le formulaire.
