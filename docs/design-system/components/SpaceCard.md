# SpaceCard

Carte d'accès à une activité, sur l'accueil d'un espace (Médias, Audio) et sur l'accueil « Aujourd'hui ». Reprend `SpaceHome`.

- Carte `surface`, bordure `line`, `radius-lg`, `shadow-1` ; toute la carte est le lien. Survol : bordure `brand`.
- Icône dans un carré `brand-soft`, titre `title-md`, équipe en `ink-muted`, compteurs en `StatusChip` (`warning` pour ce qui attend, `accent` pour le nouveau).
- Grille : une colonne sous 640px, deux au-delà, trois à partir de 1200px.
