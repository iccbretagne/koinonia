# Rendez-vous pastoral

## En une phrase

Obtenir un entretien avec un responsable pastoral, en passant par une qualification qui oriente la demande vers le bon interlocuteur avant de poser un créneau.

Remplace la sollicitation en fin de culte, qui dépend de qui est disponible sur le moment plutôt que de ce dont la personne a besoin.

## Le déclencheur

Deux portes d'entrée, selon que la personne a un compte ou non.

**Depuis l'application** : Opérations → Mes demandes → Nouvelle demande → Rendez-vous pastoral.

**Par le lien public** : un formulaire accessible sans compte, dont l'adresse est copiable depuis la vue agenda. C'est la porte pour les personnes qui ne sont pas encore dans Koinonia.

Le formulaire est identique dans les deux cas, et il est nettement plus fourni que les autres demandes :

- **Coordonnées** : nom, prénom, sexe, téléphone, adresse mail.
- **Profil** : tranche d'âge, ancienneté à l'église, statut STAR ou non, et le cas échéant le département de service.
- **Motif** de l'entretien, avec plusieurs choix possibles : renseignements, démarches administratives, vie familiale, croissance spirituelle, oppressions, maladie, service, études.
- **Jour souhaité** : mardi ou dimanche.

Ces informations ne sont pas de la paperasse : ce sont elles qui permettent la qualification.

## Qui intervient

| Acteur | Rôle dans le circuit |
|---|---|
| Le demandeur | Remplit le formulaire, avec ou sans compte |
| Le qualificateur | Examine la demande et l'oriente vers un profil pastoral |
| Le titulaire du profil pastoral | Reçoit la personne |

## Les étapes et leurs statuts

> Soumise → Qualifiée (ou Rejetée, avec motif) → Planifiée → Tenue

**La qualification.** Le qualificateur lit le motif et le profil, puis valide en assignant la demande à un profil pastoral — ou la rejette en expliquant pourquoi. C'est l'étape qui fait la différence entre un entretien utile et un rendez-vous mal orienté qu'il faudra recommencer.

**La planification.** Les demandes qualifiées arrivent dans une file à planifier, où un créneau leur est attribué en fonction du jour souhaité et des disponibilités du titulaire.

**Le rendez-vous** apparaît alors dans l'agenda hebdomadaire, sous le nom du responsable pastoral concerné.

## Où ça se passe

| Pour… | Aller à… |
|---|---|
| Déposer une demande | Mes demandes → Rendez-vous pastoral, ou le lien public |
| Qualifier | Gestion pastorale → Qualification |
| Attribuer un créneau | Gestion pastorale → Planification |
| Voir les rendez-vous de la semaine | Gestion pastorale → Vue agenda |
| Poser un rendez-vous hors circuit | Gestion pastorale → Nouvelle entrée |

## Les règles à connaître

- Les entretiens se tiennent le **mardi** et le **dimanche**. Le demandeur choisit, la planification confirme.
- Une demande **qualifiée n'est pas encore un rendez-vous** : tant qu'un créneau n'est pas attribué, rien n'est acquis pour le demandeur.
- Les informations saisies — motif, situation familiale, santé — sont sensibles. Elles ne circulent pas au-delà des personnes qui interviennent dans le circuit.

## Les cas particuliers

**Une demande venant de l'extérieur.** Le lien public permet à quelqu'un qui n'est pas encore membre de solliciter un entretien. Le circuit est le même.

**Une entrée directe.** Un rendez-vous convenu de vive voix peut être posé directement dans l'agenda, sans passer par la demande ni la qualification. À utiliser avec parcimonie : ce qui n'est pas passé par le formulaire n'a pas d'historique de motif.

**Un rejet.** Motivé, et communiqué au demandeur. Une demande rejetée n'est pas une fin de non-recevoir définitive — elle signifie souvent qu'un autre canal est plus adapté.

## Ce qui sort à la fin

- Un créneau posé dans l'agenda du responsable pastoral, visible dans la vue de la semaine.
- Le motif et le profil du demandeur restent attachés à la demande, ce qui permet de préparer l'entretien.
- Une trace de ce qui a été demandé, par qui, et comment cela a été orienté.
