# Création de l'événement

## En une phrase

Poser au calendrier un culte, une formation ou une réunion, et décider du même geste quels circuits s'ouvriront autour : les annonces, l'appel du discipolat, le compte rendu, le service d'accueil.

Remplace le calendrier qui n'existait que dans la tête du secrétariat.

## Le déclencheur

Une date est arrêtée. Le secrétariat ou un administrateur ouvre **Événements → Gérer les événements → Nouvel événement**, et renseigne :

- le **titre** et le **type** de l'événement ;
- la **date et l'heure** ;
- le **délai avant l'événement**, qui conditionne les rappels ;
- la **date limite de planification** — l'échéance au-delà de laquelle les responsables sont censés avoir rempli leur planning ;
- l'**église** concernée, dans une installation qui en héberge plusieurs ;
- la **récurrence**, pour les événements qui se répètent.

Un événement récurrent forme une **série** : il porte un marqueur, et se modifie soit unitairement, soit pour toute la série.

## Qui intervient

Le secrétariat et les administrateurs créent et configurent. Les responsables de département n'interviennent qu'ensuite, sur le planning.

## Les étapes

> Événement créé → Configuré → Départements associés → Ouvert au planning

La **configuration** est l'étape la plus sous-estimée, parce qu'elle ne coûte que quatre clics et détermine pourtant tout ce qui pourra ou non se faire ensuite :

| Interrupteur | Ce qu'il ouvre |
|---|---|
| Accepter les demandes d'annonces | L'événement apparaît dans le sélecteur au moment de soumettre une annonce |
| Suivre les présences pour le discipolat | L'événement remonte dans le module discipolat pour l'appel des disciples |
| Activer le compte rendu (et les statistiques) | Le compte rendu devient saisissable après l'événement |
| Familles de service attendues | L'événement entre dans le planning d'accueil pour l'affectation des familles |

Vient ensuite le choix des **départements associés** : ce sont eux, et eux seuls, qui verront l'événement apparaître dans leur planning. Un département oublié à cette étape est un département qui ne saura pas qu'il est attendu.

## Où ça se passe

| Pour… | Aller à… |
|---|---|
| Créer, dupliquer, modifier, supprimer | Événements → Gérer les événements |
| Configurer et associer les départements | Le bouton **Config** de l'événement |
| Ouvrir la grille de service | Le bouton **Planning** de l'événement |
| Voir le calendrier d'ensemble | Événements → Agenda de l'église |

## Les règles à connaître

- **La date limite de planification n'est pas cosmétique** : c'est elle qui déclenche les relances et qui fait apparaître le bandeau d'échéance dépassée sur la grille des responsables.
- **Dupliquer plutôt que recréer.** Un événement semblable au précédent se duplique avec sa configuration et ses départements, ce qui évite l'oubli d'un interrupteur.
- **Une série se modifie avec précaution** : la modification peut porter sur l'occurrence seule ou sur toute la suite.

## Les cas particuliers

**Un événement demandé par un responsable.** Les tuiles *Ajout*, *Modification* et *Annulation d'événement* du menu des demandes permettent à un responsable de solliciter le secrétariat sans avoir les droits de création. Le circuit aboutit ici.

**Un événement hors culte.** Formation, réunion, prière : la mécanique est identique, mais tous les interrupteurs ne se justifient pas. Un événement interne n'a pas besoin d'accepter des annonces.

**Une annulation.** Supprimer un événement fait disparaître le planning associé. Mieux vaut vérifier ce qui y est accroché avant de le faire.

## Ce qui sort à la fin

- Un événement daté, visible dans l'agenda de l'église.
- Une grille de planning ouverte pour chaque département associé.
- Les circuits avals armés ou non, selon la configuration retenue.
